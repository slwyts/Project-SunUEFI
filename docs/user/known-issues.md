# 已知问题

按使用中遇到的现象排列。功能范围见[项目状态](../status.md)。

## 切换刷新率、关屏或合盖后黑屏

屏幕以 144 Hz 启动并正常使用。切换到 60 / 120 Hz，或关屏、合盖后再亮屏，可能出现黑屏而背光仍亮。目前通常需要重启恢复。在修好之前，建议保持 144 Hz，并避免合盖和手动关屏。修正已在推进，见[显示](../devel/piano-display-depth.md)。

## UEFI 阶段屏幕白屏

集成版本在 UEFI 阶段物理屏幕可能是白的，但导出的屏幕截图内容正确，说明显示内容没有出错。Linux 启动后由 Linux 驱动重新点亮屏幕，桌面正常。原因还没有找到。

白屏时先判断固件是否在运行：

```sh
fastboot -s SunUEFI-piano getvar product
```

返回 `piano-sunuefi` 就说明固件正常。可以 `oem boot-stable` 启动 Linux，或 `reboot` 回 Android，见[UEFI Fastboot](fastboot.md)。电脑看不到设备时见[返回 Android](recovery.md)。

## 相机

前后摄像头可以预览和录像。已知问题：第一帧有绿色区域；刚打开时画面偏暗，曝光要过一会儿才稳定；对焦和画质与原厂相机有差距。针对启动曝光、对焦和帧完整性的修正已构建，还没有在平板上验证。相机目前没有专业 / 手动模式的应用入口。

## 麦克风

能录音，但声音偏小、噪声较大，桌面输入电平也不理想。声音偏小来自双声道向单声道混合时有效声道被平均衰减，单声道修正已编译，尚未装到平板上。

## 电源和睡眠

* 合盖和电源键目前只处理背光，锁屏、待机和休眠没有完成。
* 关机偶尔会回到 Android，原因未知。
* 双电池、基础 PD 充电可用；高压快充和完整充电周期没有验证。

## 启动较慢

从内核启动到桌面约一到两分钟（`systemd-analyze` 测量，不含 UEFI 阶段），仍有优化空间。详见[启动时间](../devel/piano-boot-time.md)。

## 蓝牙

蓝牙需要每台平板自己的原厂蓝牙地址，安装器会在安装时读出并写入。手工拷贝镜像而不经过安装器时，蓝牙控制器会显示“缺少地址”而不可用。蓝牙配对、设备连接和耳机播放可用；触控笔输入仍需单独适配。

## 触控笔、指纹、HDR、Windows

这些功能没有完成，见首页的[尚未完成](../../README.md#尚未完成)。

## 其他

* Recovery 里的独立 SunUEFI 镜像已放弃，见[返回 Android](recovery.md)。
* 当前运行使用 CSOT 面板配置，其他面板版本和不同内存容量的平板没有测试过。
