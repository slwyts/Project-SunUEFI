# 已知问题

按使用中遇到的现象排列。功能范围见[项目状态](../status.md)。

## 切换刷新率、关屏或合盖后黑屏

屏幕默认以 120 Hz 冷启动，保留其他刷新率模式。运行中切换刷新率，或关屏、合盖后再亮屏，可能出现黑屏而背光仍亮。目前通常需要重启恢复。在修好之前，建议保持默认 120 Hz，并避免合盖和手动关屏。修正已在推进，见[显示](../devel/piano-display-depth.md)。

## UEFI 阶段屏幕白屏

集成版本在 UEFI 阶段物理屏幕可能是白的，但导出的屏幕截图内容正确，说明显示内容没有出错。Linux 启动后由 Linux 驱动重新点亮屏幕，桌面正常。原因还没有找到。

白屏时先判断固件是否在运行：

```sh
fastboot -s SunUEFI-piano getvar product
```

返回 `piano-sunuefi` 就说明固件正常。可以 `oem boot-stable` 启动 Linux，或 `reboot` 回 Android，见[UEFI Fastboot](fastboot.md)。电脑看不到设备时见[返回 Android](recovery.md)。

## 相机

前后摄像头可以预览和录像。曝光、对焦和首帧处理仍在改善，画质与原厂相机有差距。相机目前没有完整专业模式的应用入口。

## 麦克风

已使用原生单声道录音，旧的空声道混合造成音量衰减的问题已修正。底噪和桌面输入电平仍需调校。

## 电源和睡眠

* 合盖和电源键目前只处理背光，锁屏、待机和休眠没有完成。
* 关机偶尔会回到 Android，原因未知。
* 双电池、基础 PD 充电可用；高压快充和完整充电周期没有验证。

## 启动较慢

从内核启动到桌面通常需要一到两分钟，首次启动可能更久。启动过程中可能长时间灰屏或白屏，缺少清楚的进度提示。仅凭屏幕颜色无法区分正在启动与已经停住；不要连续强制重启。当前系统直接使用内部 ext4 分区，慢启动已经不是解压整套 RAM 根系统造成的，硬件初始化和服务等待仍需优化。详见[启动时间](../devel/piano-boot-time.md)。

## 蓝牙

安装器会自动配置本机蓝牙地址。手工拷贝镜像而不经过安装器时，还需要按[蓝牙地址配置](../devel/piano-bluetooth.md)完成这一步。触控笔输入仍需单独适配。

## 触控笔、指纹、HDR、Windows

这些功能没有完成，见首页的[尚未完成](../../README.md#尚未完成)。

## 其他

* 新装系统需要自己通过 NetworkManager 保存 Wi-Fi。
* Recovery 里的独立 SunUEFI 镜像已放弃，见[返回 Android](recovery.md)。
* 当前运行使用 CSOT 面板配置，其他面板版本和不同内存容量的平板没有测试过。

## 手写笔与默认刷新率

默认产品在 piano 上以 120 Hz 冷启动，使已接通的笔输入和显示使用同一个可用配置。面板识别仍自动选择 BOE／CSOT，其他刷新率模式仍保留。运行中切换刷新率可能黑屏，暂时保持默认；完整模式切换修复后再恢复更灵活的选择。
